# THEOS-2 Mission Viewer

เว็บแอปไฟล์เดียว (static) สำหรับดู **คำสั่งถ่ายภาพ (IR Status)** และ **ปฏิทิน Orbit** ของดาวเทียม THEOS-2 บนแผนที่เดียวกัน

## ฟีเจอร์
- **แท็บ "คำสั่งถ่ายภาพ"**: อ่านไฟล์ `ImageRequestStatus` (.xml) แสดงเป็นตาราง ค้นหา กรองสถานะ แก้สถานะ และ Export CSV / GeoJSON
- **แท็บ "แผนที่ + Orbit"**: แสดง AOI ของคำสั่ง IR ซ้อนกับแนว Orbit ตามวันที่เลือกในปฏิทิน (รอบวงโคจรซ้ำทุก 26 วัน)
- สีแนว Orbit: เส้นทางหลัก = เขียว, ชุดย่อย 10 = ม่วงอ่อน, 20 = เขียวมะนาว, 30 = น้ำเงิน
- นำเข้าไฟล์ `.geojson` ได้ที่แผงปฏิทิน Orbit ตั้งชื่อไฟล์ `Orbit_###.geojson` หรือ `Orbit_###_10/20/30.geojson` (ชุดย่อย) ไฟล์ที่นำเข้าเก็บในเบราว์เซอร์ของผู้ใช้แต่ละคน
- ชุดย่อย 10/20/30 ฝังไว้ให้ทุก Orbit แล้ว: ของ Orbit 273 เป็นไฟล์จริง ส่วน Orbit อื่นคำนวณจากแนวเส้นทางด้วยกฎเดียวกับ 273 (เลื่อนซ้าย-ขวาคงที่ 111.4 / 230.9 / 365.8 กม.) หากนำเข้าไฟล์จริงชื่อเดียวกัน ไฟล์ที่นำเข้าจะมาแทนที่
- ข้อมูล Orbit_273–289 ฝังอยู่ใน `index.html` ไม่ต้องมีเซิร์ฟเวอร์หรือขั้นตอน build

## ใช้งาน
เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือเปิดผ่าน GitHub Pages (ดูด้านล่าง)

## ข้อควรรู้
- สถานะที่แก้และไฟล์ XML ที่โหลดเก็บในเบราว์เซอร์ของแต่ละคน (localStorage) ไม่แชร์ข้ามเครื่อง
- แผนที่ Google ใช้ไทล์ผ่านลิงก์ตรง ซึ่งไม่ใช่ช่องทางทางการของ Google เหมาะกับใช้ส่วนตัว/กลุ่มเล็ก
  ถ้าเปิดสาธารณะ ควรเปลี่ยนเป็น OpenStreetMap หรือ Google Maps API
- ต้องต่ออินเทอร์เน็ตเพื่อโหลด Leaflet (cdnjs) และไทล์แผนที่

## เผยแพร่ด้วย GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save

## แชร์ข้อมูลร่วมกัน (ไม่บังคับ)
โดยปริยายข้อมูลเก็บในเบราว์เซอร์ของแต่ละคน ถ้าต้องการให้เพื่อนเห็นการแก้ไขด้วยกัน (สถานะคำสั่ง, ไฟล์ XML ที่โหลด, ไฟล์ .geojson ที่นำเข้า):
1. สร้างโปรเจกต์ที่ script.google.com วางโค้ดจาก `apps-script/Code.gs` แล้วเปลี่ยนค่า `KEY` เป็นรหัสลับ
2. Deploy → New deployment → Web app → Execute as: Me, Who has access: Anyone → คัดลอก URL (ลงท้าย `/exec`)
3. เปิด `index.html` แก้ `window.SYNC_URL` และ `window.SYNC_KEY` (ตรงกับ `KEY`) แล้ว commit
4. หน้าเว็บจะดึงข้อมูลใหม่ทุก 30 วินาที (คลิกป้ายสถานะเพื่อซิงค์ทันทีและดูรายละเอียดข้อผิดพลาด) และแสดงสถานะที่มุมบนขวา

หมายเหตุ: รหัสลับอยู่ในหน้าเว็บ ใครเปิดลิงก์ได้ก็เห็นและแก้ข้อมูลร่วมกันได้ เหมาะกับกลุ่มเพื่อนที่ไว้ใจกัน ไม่ใช่ระบบสิทธิ์จริงจัง

### ถ้าเพื่อนไม่เห็นข้อมูล ให้ตรวจตามนี้
- เพื่อนต้องเปิด **เวอร์ชันที่ push แล้ว** (มี `SYNC_URL`) ไม่ใช่ไฟล์เก่าในเครื่อง และกดรีเฟรชแบบแรง (Ctrl+F5)
- ป้ายมุมบนขวาขึ้น "รหัสลับไม่ตรง" → `SYNC_KEY` ต้องเท่ากับ `KEY` ใน Code.gs (เว้นว่างทั้งคู่ได้)
- ป้ายขึ้น "สิทธิ์/URL ไม่ถูกต้อง" → Deploy ต้องเป็น Who has access: **Anyone** และใช้ URL ลงท้าย `/exec`
- หลังแก้ Code.gs ทุกครั้งต้อง Deploy → Manage deployments → Edit → Version: New version
- ไฟล์ XML/.geojson ที่นำเข้าจะค้างไว้ในเบราว์เซอร์และบนเซิร์ฟเวอร์ นำเข้าไฟล์ชื่อเดิมซ้ำเพื่อ **อัปเดตทับ** ได้
